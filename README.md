# 🎨 PySide6 - Jornada de Aprendizado

Repositório dedicado aos meus estudos de **PySide6**, o framework oficial do Qt para desenvolvimento de interfaces gráficas (GUI) em Python.

O objetivo deste projeto é aprender desde os conceitos básicos até aplicações mais completas, documentando exemplos, desafios e projetos ao longo do caminho.

---

## 📚 O que é o PySide6?

O **PySide6** é o conjunto oficial de bindings do **Qt 6** para Python, permitindo criar aplicações desktop modernas e multiplataforma (Windows, Linux e macOS).

Com ele é possível desenvolver:

* Aplicações desktop
* Ferramentas de produtividade
* Sistemas administrativos
* Interfaces para automação
* Dashboards
* Aplicações multimídia

# ▶️ Instalação

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/pyside6_tutorial.git
cd pyside6_tutorial
```

Crie um ambiente virtual:

### Linux/macOS

```bash
python -m venv .venv
source .venv/bin/activate
```

### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

ou apenas:

```bash
pip install pyside6
```
