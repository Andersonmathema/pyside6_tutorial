PySide6 — Signals, Slots & Events
================================

Exercícios baseados na sequência de tópicos do tutorial:
https://www.pythonguis.com/tutorials/pyside6-signals-slots-events/

Arquivos:
01 a 22  -> exercícios progressivos
23       -> projeto final

Como usar:
1. Abra esta pasta no VS Code.
2. Ative seu ambiente virtual.
3. Instale PySide6, se necessário:

   python -m pip install PySide6

4. Execute um exercício:

   python 01_primeiro_sinal.py

Os arquivos possuem TODOs e trechos incompletos propositalmente.
Não há gabarito dentro desta pasta.
